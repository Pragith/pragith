Caffeinate-d

A small native macOS menu-bar wrapper for caffeinate -d, providing a visible toggle for preventing display sleep.

Repository and source download

Scope

Caffeinate-d starts and stops the macOS system command that keeps the display awake. It is intentionally limited to this menu-bar interaction and does not claim broader power-management control.

Release state: the repository declares source version 0.2.0. GitHub does not currently provide a matching packaged release or signed binary download.

Privacy

The application is designed to invoke the local macOS power-management command. The source does not require an account or remote service. This statement applies to the published source and should be reviewed again for every packaged release.
